SEB TURNS 26 — GITHUB PAGES

1. Create a new public GitHub repository named: seb-turns-26
2. Open the downloaded ZIP and extract it.
3. Upload index.html and the assets folder to the repository.
   Do not upload the ZIP itself.
4. Commit the files to the main branch.
5. Open Settings → Pages.
6. Under "Build and deployment", choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.

The website should appear at:
https://madebyyasha.github.io/seb-turns-26/

GitHub can take a few minutes to publish it for the first time.
